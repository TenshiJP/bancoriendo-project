# Bancoriendo

Este repositorio contiene los componentes desarrollados para simular la infraestructura tecnológica del sistema **BANCORIENDO**, utilizada como entorno de laboratorio para la ejecución de una auditoría informática.

---

## 🎯 Propósito

Este laboratorio fue diseñado con fines académicos para:

- Simular un entorno transaccional bancario
- Ejecutar pruebas de auditoría técnica
- Identificar vulnerabilidades y riesgos
- Generar evidencia para el análisis de seguridad

---

## 🚀 Arquitectura del Sistema

El sistema se compone de los siguientes módulos:

- **App Web (PHP):** Interfaz de usuario para la gestión de transacciones
- **API Core:** Lógica de negocio y acceso a datos
- **Core Worker:** Procesamiento de tareas asíncronas
- **API Tokens:** Servicio de autenticación y validación de tokens
- **WebSocket Service (Node.js):** Comunicación en tiempo real
- **RabbitMQ:** Broker de mensajería para integración de servicios
- **Node-RED:** Orquestación de flujos de integración
  
---

## 🛠️ Tecnologías Utilizadas

- **Lenguajes:** Python, PHP, JavaScript (Node.js)
- **Mensajería:** RabbitMQ
- **Orquestación:** Node-RED
- **Base de datos:** MySQL, PostgreSQL
- **Servidor de archivos: Samba
- **Protocolos:** HTTP/REST, WebSockets, FTP
- **Control de versiones:** Git / GitHub

---

## 🔗 Relación con la Auditoría

Este repositorio complementa el informe de auditoría del entorno BANCORIENDO, proporcionando el contexto técnico de los servicios evaluados, así como soporte para la evidencia generada durante la fase de ejecución.
